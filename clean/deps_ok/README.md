# clean/deps_ok — SCA 음성 세트 (독립 스캔 전용)

SCA 룰은 저장소 전체의 매니페스트·lock을 하나로 본다(파서가 `rglob`으로 훑는다).
여기에 진짜 `requirements.txt`·`package.json`을 두면 `vulnerable/`의 SCA-09·11·12가
꺼지거나 컴포넌트 목록이 섞여 양성이 마스킹된다 — 명세 §6 각주.

그래서 이 디렉토리의 매니페스트 견본은 **파서 대상 밖 확장자**로 둔다
(`*.txt.off`·`*.json.off`). SCA 음성을 실제로 측정하려면 이 파일들의 확장자를
되돌린 트리를 따로 만들어 **독립 스캔**한다.
